# 003 - Layout & Responsive Design

Materi ini fokus pada teknik layout responsif menggunakan Tailwind CSS. Anda akan belajar memanfaatkan Flexbox, CSS Grid, dan utilities positioning untuk membangun struktur halaman kompleks dengan mudah.

## 🎯 Tujuan Pembelajaran

- Menggunakan utility Flexbox dan Grid untuk menyusun layout
- Menerapkan strategi mobile-first dengan breakpoint Tailwind
- Mengatur alignment, ordering, dan distribution konten
- Memanfaatkan utilities positioning, z-index, dan transform
- Membuat komposisi section realistis (hero, features, pricing)

## 🧱 Topik yang Dibahas

1. **Container & Breakpoints**  
   Mengatur lebar maksimal dan padding adaptif di berbagai device.

2. **Flexbox Utilities**  
   Mengontrol axis, wrap, alignment, dan order.

3. **CSS Grid Utilities**  
   Membuat grid responsif dengan repeat, auto-fit, dan gap.

4. **Advanced Layout**  
   Teknik split layout, card masonry, dan sticky sidebar.

5. **Responsive Patterns**  
   Menangani nested grid, stacking order, dan reflow konten.

## 🛠️ Aktivitas di Demo

- Membangun hero section dengan layout responsif
- Menyusun grid kartu adaptif yang mudah dikustomisasi
- Membuat pricing table dengan utility `grid-cols` dan `gap`
- Menggunakan `lg:grid-cols-[auto,1fr]` untuk layout kompleks

## 🔍 Highlight

- Variasi penggunaan `flex`, `grid`, `gap`, `place-content`
- Kombinasi responsive + dark mode tanpa CSS custom
- Perbedaan `auto-fit` vs `auto-fill` dalam grid Tailwind

Production & Optimization

Optimalkan Tailwind untuk rilis production: konfigurasi build, purge otomatis, monitoring performa, dan pipeline CI/CD yang aman.

Tailwind CLI Workflow

Setup minimal menggunakan Tailwind CLI + Autoprefixer. Tambahkan script build & watch di package.json.

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

// package.json
{
  "scripts": {
    "dev": "tailwindcss -i ./src/input.css -o ./dist/output.css --watch",
    "build": "tailwindcss -i ./src/input.css -o ./dist/output.css --minify"
  }
}

Content Scanning

Pastikan daftar file pada `content` mencakup semua template. Gunakan glob pattern yang tepat.

// tailwind.config.js
module.exports = {
  content: [
    "./src/**/*.{html,js,ts,jsx,tsx}",
    "./components/**/*.{vue,js}",
    "./pages/**/*.{mdx,md}",
  ],
  safelist: [
    { pattern: /bg-(primary|accent)-(500|600)/ },
    'animate-spin',
  ],
}

Checklist Deploy

  • Pastikan CSS output < 100KB gzip
  • Aktifkan HTTP/2 + gzip/brotli di server
  • Prefetch font & critical assets
  • Gunakan cache busting (hashing file)

Monitoring

Integrasi dengan Lighthouse CI, Sentry, dan Splitbee/Analytics untuk memantau performa serta error setelah deployment.

Bundle Comparison

Development vs Production

Development Build

  • Ukuran CSS: 3.4 MB
  • Source map: Aktif
  • Mode JIT: Aktif
  • Minify: Tidak

Production Build

  • Ukuran CSS: 38 KB
  • Source map: Opsional
  • Mode JIT: Aktif
  • Minify: Tailwind CLI

Pipeline CI/CD Contoh

1 · Install

Install dependencies dan jalankan unit test.

npm ci
npm run lint
npm run test

2 · Build

Generate CSS production + bundling JS.

npm run build
npm run generate:pages

3 · Deploy

Upload ke CDN, invalidasi cache, dan jalankan smoke test.

npx wrangler publish
npm run test:e2e

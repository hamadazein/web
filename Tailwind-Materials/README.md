# Tailwind CSS Learning Materials

Selamat datang di Tailwind CSS Learning Materials! Koleksi materi ini dirancang untuk membantu Anda menguasai Tailwind CSS secara bertahap, mulai dari konsep dasar hingga implementasi production-ready.

## 📚 Daftar Materi

### 001 - Tailwind Introduction
- Pengantar konsep utility-first
- Cara instalasi Tailwind (CDN, CLI, PostCSS, Vite)
- Struktur proyek Tailwind dan workflow build
- Membandingkan Tailwind dengan framework CSS lainnya

### 002 - Utility-First Fundamentals
- Konvensi penamaan kelas Tailwind
- Spacing, sizing, typography, dan color utilities
- Responsive variants (sm, md, lg, xl, 2xl)
- State variants (hover, focus, active) dan dark mode

### 003 - Layout & Responsive Design
- Container, breakpoints, dan responsive grid
- Flexbox & Grid utilities di Tailwind
- Positioning, z-index, dan transforms
- Strategi mobile-first dengan Tailwind

### 004 - Components & Patterns
- Membuat komponen UI reusable (Navbar, Cards, Hero)
- Teknik composition dengan utility classes
- Menggunakan @apply untuk ekstraksi style
- Integrasi dengan Headless UI & Radix

### 005 - Forms & Interactivity
- Styling form controls native
- Fokus pada accessibility (focus ring, aria)
- Validation states dan feedback UI
- Interaksi dengan Alpine.js / React

### 006 - Customization & Theming
- Konfigurasi `tailwind.config.js`
- Custom colors, fonts, spacing, shadows
- Plugin resmi dan community plugin
- Mode JIT dan dynamic theming

### 007 - Production & Optimization
- Purge dan tree-shaking otomatis
- Optimasi performa dan ukuran file
- Integrasi dengan build tools (Vite, Next.js, Laravel)
- Deploy dan maintenance di production

## 🎯 Hasil Akhir Pembelajaran

Setelah menyelesaikan seluruh materi, Anda akan mampu:

1. Membangun UI modern dan responsif dengan Tailwind secara efisien
2. Membuat design system utility-first yang konsisten
3. Mengintegrasikan Tailwind dengan framework JavaScript populer
4. Menyusun workflow build yang optimal untuk proyek besar
5. Menerapkan best practice aksesibilitas dan performa di Tailwind

## 🚀 Cara Menggunakan

1. Mulai dari folder `001 Tailwind Introduction`
2. Ikuti urutan materi secara berkelanjutan
3. Jalankan contoh kode dan eksperimen variasinya
4. Terapkan konsep pada mini project di setiap bab
5. Selesaikan "Tailwind Best Practice Project" sebagai proyek akhir

## 💡 Tips Belajar

- Biasakan membaca dokumentasi resmi Tailwind
- Manfaatkan IntelliSense untuk auto-complete kelas
- Gunakan DevTools untuk memeriksa layout secara real-time
- Kombinasikan dengan plugin atau komponen Headless UI
- Selalu uji di berbagai ukuran layar dan mode gelap/terang

# 001 - Tailwind Introduction

Pada materi pertama ini, Anda akan mengenal Tailwind CSS sebagai framework utility-first. Fokus utamanya adalah memahami mindset, struktur dasar, dan bagaimana memulai proyek Tailwind dengan berbagai pendekatan.

## 🎯 Tujuan Pembelajaran

- Memahami perbedaan Tailwind dengan framework berbasis komponen
- Mengetahui opsi instalasi (CDN, CLI, build tool)
- Memahami konfigurasi dasar `tailwind.config.js`
- Menjalankan Tailwind Playground untuk eksperimen cepat

## 🧠 Konsep Utama

1. **Utility-First Mindset**  
   Tailwind menyediakan utility classes kecil yang dikombinasikan untuk membentuk UI. Tidak ada komponen bawaan seperti Bootstrap.

2. **Just-In-Time Compiler**  
   Sejak Tailwind v3, JIT diaktifkan secara default, menghasilkan ukuran CSS minimal berdasarkan kelas yang digunakan.

3. **Workflow Fleksibel**  
   - CDN untuk prototyping
   - CLI / PostCSS untuk proyek production-ready
   - Integrasi dengan Vite, Next.js, Laravel, dan lain-lain

4. **Konfigurasi Kustom**  
   File `tailwind.config.js` memungkinkan Anda menyesuaikan warna, font, spacing, dan plugin.

## 🛠️ Apa yang Anda Lakukan di Demo

- Mengaktifkan Tailwind lewat CDN
- Menggunakan direktif `@tailwind` di CSS custom
- Melihat bagaimana kelas Tailwind langsung memengaruhi tampilan
- Mengaktifkan dark mode menggunakan toggle sederhana

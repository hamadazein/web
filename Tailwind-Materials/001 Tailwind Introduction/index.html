Utility-first = custom UI tanpa menulis CSS panjang. Reusable, konsisten, dan mudah di-maintain.

Class Breakdown

  • bg-gradient-to-br from-brand-600 via-indigo-600 to-sky-500 → Gradien instan tanpa CSS custom
  • rounded-2xl shadow-xl → Corners & shadow tinggal pakai
  • px-4 py-2 font-semibold → Spacing & font yang konsisten

Responsive & Dark Mode

Gunakan prefix responsive (sm:, md:, lg:, xl:) serta dark mode class untuk menyesuaikan tampilan.

sm:text-left md:text-center lg:text-right

Text ini adaptif sesuai breakpoint.

dark:bg-slate-800 dark:text-white

Aktifkan toggle di atas untuk melihat mode gelap.

grid grid-cols-1 gap-3 sm:grid-cols-2

Instalasi Tailwind

  1. CDN (Prototyping) 
    <script src="https://cdn.tailwindcss.com"></script>
  2. CLI / Build Tool 
    npm install -D tailwindcss
npx tailwindcss init
  3. Konfigurasi CSS 
    @tailwind base;
@tailwind components;
@tailwind utilities;

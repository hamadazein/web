Customization & Theming

Tailwind mudah dikustomisasi untuk mengikuti brand guideline. Contoh di sini menunjukkan penggunaan config extend, design tokens, plugin, dan toggle tema multi state.

Konfigurasi Tailwind

// tailwind.config.js
module.exports = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        brand: {
          50: '#f5f3ff',
          500: '#a855f7',
          600: '#9333ea',
        },
        accent: {
          500: '#f97316',
          600: '#ea580c'
        }
      },
      boxShadow: {
        glass: '0 25px 60px -15px rgba(79, 70, 229, 0.45)'
      }
    }
  },
  plugins: [
    require('@tailwindcss/forms'),
    require('@tailwindcss/typography'),
  ]
}

Glassmorphism Utility

Tambahkan custom utility melalui @layer utilities.

@layer utilities {
  .glass-panel {
    @apply bg-white/10 backdrop-blur-xl border border-white/15
           shadow-glass rounded-3xl;
  }
}

Multi Theme Toggle

Simulasikan data-theme pada root dan gunakan variant arbitrary [data-theme=dark]:bg-slate-950.

Safelist

Tambahkan ke config untuk kelas dinamis:

safelist: [
  { pattern: /bg-brand-(500|600)/ },
  'text-accent-500',
  'border-accent-600',
]

Utility-First Design System

Dengan Tailwind, design system dapat dikelola melalui konfigurasi. Warna, spacing, dan typography didefinisikan sekali lalu digunakan di seluruh aplikasi.

  • Konfigurasi theme yang konsisten
  • Penggunaan plugin resmi untuk konten khusus
  • Safelist untuk class dinamis di runtime

"Tailwind memungkinkan tim frontend dan design berbicara bahasa yang sama: utility classes."

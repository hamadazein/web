# 002 - Utility-First Fundamentals

Materi ini mendalami utilitas inti yang membuat Tailwind CSS sangat powerful. Anda akan mempelajari pola penamaan kelas, variant responsive dan state, serta teknik kombinasi utilitas untuk menciptakan UI yang rapi dan konsisten.

## 🎯 Tujuan Pembelajaran

- Memahami kategori utilitas utama (layout, spacing, typography, color)
- Menggunakan responsive variants (`sm:`, `md:`, `lg:`, `xl:`, `2xl:`)
- Mengaplikasikan state variants (`hover:`, `focus:`, `active:`, `disabled:`)
- Menerapkan dark mode dan conditional styling

## 🧩 Topik Utama

1. **Spacing & Sizing Utilities**  
   Mengatur padding, margin, width, height, dan gap secara presisi.

2. **Typography & Color System**  
   Mengontrol font, ukuran, weight, leading, tracking, dan warna.

3. **Responsive Variants**  
   Membuat UI mobile-first hanya dengan menambahkan prefix breakpoint.

4. **State Variants & Pseudo-class**  
   Menerapkan gaya berbeda saat hover, focus, active, disabled, hingga data attribute.

5. **Dark Mode & Media Queries**  
   Aktivasi dark mode menggunakan class atau preferensi OS.

## 🔍 Aktivitas di Demo

- Mengubah layout dengan utility spacing
- Membuat typography scale yang konsisten
- Menguji responsive behavior langsung dari viewport
- Menambahkan hover/focus state tanpa menulis CSS manual

## 📦 Output yang Diharapkan

Anda akan nyaman membaca dan menulis kelas Tailwind tanpa kebingungan, memahami pola penamaan, serta mengetahui di mana harus mencari utilitas yang dibutuhkan.

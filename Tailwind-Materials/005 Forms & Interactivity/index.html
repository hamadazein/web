Forms & Interactivity

Tailwind mempermudah styling form control dan interaktivitas ringan. Komponen di bawah menunjukkan pola validasi, focus ring, toggle, dan alert dengan JavaScript minimal.

Validation States

Inline Interactivity

`peer` dan `data-*` variants mempermudah toggling state tanpa JavaScript berat.

peer-checked:bg-primary-500/60

data-[state=open]:rotate-180

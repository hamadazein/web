# Weblab Implementation Plan

**Goal:** Deliver a working, enjoyable Indonesian learning platform on the existing static repository.

**Architecture:** Use native modules, generated curriculum metadata, sanitized Markdown, and browser-local state. Preserve source materials and static hosting under subpaths.

**Tech Stack:** HTML, CSS, JavaScript, Node tooling, Marked, DOMPurify, Inter, Playwright, axe.

## Global constraints

- Requested font stack and local Inter fallback.
- No account required; no fabricated learner metrics.
- 320px minimum layout, keyboard access, readable contrast, reduced motion.
- Existing source lessons and project examples remain intact.

## Tasks

- [x] Tooling and curriculum: add package scripts, scripts/build.mjs and scripts/serve.mjs; discover all four paths from actual README filenames; verify metadata and resources using `node --test tests/*.test.mjs`.
- [x] Learning state: assets/js/state.mjs implements validated local state, completion, bookmarks, last lesson and preferences; test corruption, duplicate completions and unavailable storage.
- [x] Interface: replace index.html and style.css; implement assets/js/app.mjs, views.mjs, reader.mjs and playground.mjs. Hash routes cover home, catalog, course, lesson, saved, progress and playground. Build locally with `npm run build`.
- [x] Integration: link every route to real curriculum, sanitize Markdown, resolve relative images, persist playground drafts, and update three legacy landing pages.
- [x] Verification: use `npm test`, `npm run test:e2e` and browser screenshots. Check phone, tablet, desktop, deep routes, unavailable storage, missing lesson, and keyboard flows. Document `npm start` and static hosting in README.
